# 客户端身份与在线状态

一个安装实例由数据目录 config.json 中的 source_id 标识。正常升级保留该文件；删除数据目录后重新初始化会产生新身份，历史节点仍保留原来的结果归属。

托管任务启动器通过 AFX_TASK_HOME 向所有子进程传入安装目录。结果环境采集优先使用这个目录，不从 runs/<run-id>/tasks.sqlite 的层级推算安装目录。配置缺失或损坏时任务失败，不能回退到 hostname 创建新的托管身份。

控制心跳使用当前安装环境，不能从历史结果恢复身份或版本。结果上传继续使用结果生成时记录的 installation_id；不含身份的旧结果保留原有 hostname 兼容行为，不批量改写历史归属。

服务端仅用五分钟内的心跳判定在线。last_seen_at 表示最近心跳或数据请求，页面称为“最后活动”，它不代表客户端在线。上传不能覆盖已有心跳维护的客户端版本、hostname、芯片或目录，也不能恢复已删除节点的展示；有效心跳可以恢复该节点。客户端删除校验与运维统计共享心跳在线规则。
