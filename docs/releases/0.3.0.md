# AutofuseX 0.3.0

0.3.0 是重构后的正式版本，统一客户端、执行引擎、工作负载、结果存储、离线查看器和中心服务的模块边界。

- 客户端采用单安装模式，从调用 `afx` 的 Python 环境启动；更新在同一环境安装，失败时使用预缓存 wheel 回退。
- 公开命令统一为 `afx`，同时支持 `python -m afx`；daemon 由客户端内部管理。
- 中心服务与离线查看器共享网页资源，包含新的运行概览、Shape 统计、设备和上传状态展示。
- 执行端保留已有 Torch/CANN 解释器，通过注册执行环境运行任务，并保留后端图转储及 Autofuse DFX 路径。

## 安装与迁移

新客户端安装：

```bash
python -m pip install 'autofusex[execution]==0.3.0'
afx init --token YOUR_TOKEN
afx start
```

旧版 0.2.x 客户端需先停止任务并等待退出，再停止旧 daemon/supervisor，在选定的唯一 Python 环境中通过 pip 重装。继续使用原 data-dir，保留身份、token、配置、结果和上传游标，不要重新 init。0.2.4.x 旧升级器不支持直接安装此版本。完整步骤见[单安装客户端说明](../single_install_client.md)。

本版本发布及中心服务部署不会向现有客户端下发统一升级，也不会替用户停止或启动业务任务。中心服务部署保留数据目录、用户及 token，并在切换前保存私有一致备份。

服务端部署采用本地干净源码构建的 0.3.0 wheel；验证完成后再推送发布标签，由 GitHub 镜像流水线发布 Release 与 PyPI。
